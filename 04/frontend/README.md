# Задание

* Бэкенд из репозитария https://github.com/kaineer/2026-04-backend запускается командой npm start и доступен по url http://localhost:5000/

* Доступные запросы:

  * **GET** /task - возвращает полный список задач
  * **POST** /task - создает новую задачу
    * параметры запроса:
      * title: string - заголовок новой задачи
    * возвращаемое значение:
      * id: string - id новой задачи
      * title: string - заголовок, что мы ввели
      * created_at: date - когда задача была создана
      * done: boolean - выполнена ли задача
  * **PUT** /task/:id - обновляет состояние задачи
    * параметры запроса:
      * title: string - заголовок новой задачи
      * done: boolean - выполнена ли задача
  * **DELETE** /task/:id - удаляет задачу из списка
    * возвращаемое значение:
      * ok: boolean - удалось ли задачу удалить
